Urutan menu beranda

Backup & Pemulihan Data

SEMUA DATA

Satu file cadangan menyimpan data Rekening, Sallary, Budget Bulanan, Traveling, MyMemo, serta laporan bulanan dan pengaturan beranda.

Hapus Semua Data

PERMANEN

Menghapus data Rekening, Sallary, Budget Bulanan, Traveling, dan MyMemo dari perangkat ini. Buat backup terlebih dahulu jika masih diperlukan.

Penyimpanan

Data MyBudget disimpan di penyimpanan lokal browser pada perangkat ini. Ekspor file cadangan secara berkala agar data tidak hilang saat data browser dibersihkan.
